Drop your retro application icons in this folder.

The Applications Explorer now uses one shared folder icon for every folder tile:
- /icons/applications/folder.png

Project detail windows can still use per-project icons if you add public paths
to the matching project in the local content editor, for example:
- /icons/applications/projects/encryption-application.png

You can add icons for:
- the shared explorer folder icon
- optional per-project detail icons

If an icon path is missing, the explorer keeps the built-in blank placeholder.
